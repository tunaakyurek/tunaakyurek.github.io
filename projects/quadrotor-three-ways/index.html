Independent research · simulation (PyBullet, acados) · Summer 2026

A unified benchmark for geometric, optimal and learned quadrotor control

A modular quadrotor control benchmark in PyBullet and acados that places geometric SE(3) control, nonlinear MPC, and reinforcement-learning policies behind a single state-to-wrench interface, wind-disturbance model, and latency-profiling pipeline.

Platform
Quadrotor dynamics in PyBullet (gym-pybullet-drones) with acados SQP-RTI solver and ROS 2 / PX4 SITL bridge
Role
Architecture design, C++/Python controller implementations, acados NMPC formulation, and tracking/latency benchmarking.
Key results
  • 0.22 vs 1.11 m position RMSE, NMPC vs. geometric SE(3) control under actuator-saturating trajectories

Modality

Overview

Published comparisons between analytical geometric controllers, nonlinear model predictive control (NMPC), and reinforcement-learning policies for quadrotors frequently differ in their underlying plant dynamics, rotor-saturation limits, wind models, and coordinate conventions. This project establishes a unified software architecture in which classical, optimal, and learned controllers implement an identical state-to-wrench interface and execute inside the same deterministic simulation loop, disturbance model, and evaluation pipeline.

System architecture & controller suite

  • Shared plant and disturbance stack. A 240 Hz PyBullet rigid-body plant with a 100 Hz outer control loop models motor time constants, rotor thrust saturation, and spatially correlated Dryden/Ornstein–Uhlenbeck wind gusts, paired with a 100 Hz ROS 2 / PX4 SITL transport bridge[4].
  • Controller implementations. The modular controller interface supports:
    1. Geometric SE(3) tracking control (Lee et al., 2010), implemented in both Python and C++ (pybind11).
    2. Nonlinear MPC (NMPC) formulated in acados using real-time iteration sequential quadratic programming (SQP-RTI, horizon N = 20) with explicit rotor-thrust box constraints.
    3. Learning and imitation pipelines supporting PPO, SAC, behavioural cloning from the NMPC demonstrator, and Bayesian gain optimization[5].

Tracking & real-time compute profiling

  • Tracking under actuator saturation. On high-acceleration figure-eight trajectories that drive unconstrained controllers into rotor saturation, acados NMPC respects per-rotor thrust bounds over the 20-step lookahead horizon and achieves 0.22 m position RMSE (zero divergence across 5 seeds), whereas the unconstrained geometric SE(3) controller saturates rotor thrust commands during 42 % of the trajectory and incurs 1.11 m position RMSE[1]. Across nominal tracking regimes and paired 200-episode wind-disturbance sweeps, both model-based families maintain stable tracking[3].
  • Solver vs. wrapper latency decomposition. Profiling the 100 Hz (10 ms budget) control loop isolates where compute time is spent: the compiled C acados SQP-RTI solver requires only 0.18–0.39 ms per QP solve (comparable to 0.7–1.2 ms for the full geometric SE(3) update), whereas Python-side horizon reference staging accounts for the 19–28 ms total step time—motivating moving reference generation into the compiled C++/pybind11 layer[2].
