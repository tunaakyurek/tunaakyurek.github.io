Work / Actuated sonar-ring autonomy

Senior design project (EE491–492) · Boğaziçi University · Intelligent Systems Laboratory · Sep 2025 – Jun 2026

Actuated Eight-Sonar Ring Autonomy: Probabilistic Cone-Voxel Mapping and Maze Exploration

A Kobuki mobile robot that autonomously explores an unknown maze, constructs a probabilistic occupancy map, and navigates to a goal using only an actuated ring of eight HC-SR04 ultrasonic sensors. The shared ROS 2 stack completed all ten simulated benchmark mazes and a full-stack physical maze run.

Platform
Kobuki base carrying an actuated ring of eight HC-SR04 sensors; Gazebo simulation running the same ROS 2 stack
Role
Co-authored with Yakup Çalın, advised by Prof. H. Işıl Bozma. Led the MATLAB sensor-fusion modeling, ROS 2 hardware integration on the Kobuki, and custom STM32H7 ultrasonic node PCB design.

  • 42 / 43 navigation goals reached during autonomous maze traversal on the physical robot

hardware · simulation — multi-maze benchmark evaluated in Gazebo; physical evaluation covers one full-stack maze run and bench prototypes.

Overview

Low-cost ultrasonic rangers operate reliably across ambient lighting variations and optically transparent or featureless walls, but each echo returns only a single scalar range integrated across a wide (~60°) acoustic cone. This project investigates whether a differential-drive mobile robot can autonomously explore, map, and navigate an unknown multi-corridor maze using exclusively an actuated ring of eight HC-SR04 ultrasonic sensors combined with wheel odometry and onboard IMU state estimation[8].

System architecture & methodology

  • Actuated acoustic ring and crosstalk-gated scheduling. Eight HC-SR04 transducers are mounted at 45° azimuthal intervals on SG90 servo stages that sweep across a 45°–135° mechanical span (5° steps in simulation, 1° steps on hardware; ±31° ring coverage diagnostic in Figure 11). Two Arduino Mega 2560 + RAMPS 1.4 controllers trigger four sensors per board in a deterministic sequence ({3, 1, 0, 2}) with a 30 ms inter-firing guard interval and stream range packets over 38,400 baud serial links to prevent acoustic crosstalk between adjacent cones[7].
  • Probabilistic 3-D cone-voxel mapping. Rather than projecting ultrasonic ranges as thin rays, each echo updates the full 3-D acoustic cone inside a persistent voxel grid (0.05 m resolution): cells preceding the range shell receive distance-weighted free-space log-odds updates while cells on the range shell accumulate Beta evidence counts (α, β) with angular weighting w(θ) = exp(−(θ/σ_θ)²) that separate unobserved space from conflicting multi-angle returns. A confidence-gated 2-D occupancy projection feeds the Nav2 planner[13].
  • Unified stop-and-sweep ROS 2 autonomy. The mission executive (maze_explorer_node) alternates between frontier-driven navigation and stationary rotational sweeps through a shared ROS 2 /scan_trigger handshake (custom_odom_node → voxel_grid_mapper_node → Nav2), executing identical mapping, frontier extraction, and navigation software in Gazebo simulation and on the physical Kobuki platform[11].
  • Custom STM32H7 ultrasonic node prototype. Alongside the dual-Arduino ring controller used in the autonomous robot trials, a custom STM32H7 ultrasonic sensor-node PCB (Figure 10) was designed in DipTrace, assembled, and bench-probed as a hardware prototype for low-latency 40 kHz analog envelope and time-of-flight acquisition[6].

Experimental evaluation

Physical maze traversal

Deployed in a physical cardboard maze, the Kobuki robot autonomously explored the unknown layout and reached the goal marker over a 4.27 m trajectory comprising 50 stop-and-scan cycles (494.6 s active duration), reaching 42 of 43 sequential navigation waypoints without recovery manoeuvres[3]. Evaluated against the reference floor plan (2,530 grid cells at 0.05 m resolution), the sonar-derived occupancy map achieved 48.3 % area coverage (1,222 mapped cells) and 0.151 occupied-cell IoU, capturing the navigable corridor topology required for collision-free path planning[4].

Multi-maze simulation benchmark

Across ten 8.6 m × 8.6 m procedural maze geometries in Gazebo, the autonomy stack completed 10 of 10 benchmark mazes within the 0.30 m goal tolerance (46–109 scans, path lengths 13.28–29.53 m, path ratios 1.02–1.24, overall map accuracy 0.902–0.921, occupied-cell IoU 0.067–0.151)[1][10], and completed 12 of 12 repeated trials across the four longest multi-corridor layouts (Mazes 00, 05, 07, and 09)[2][14]. Controlled panel-ablation experiments (180 trials across six sensor/sweep configurations; Figures 8–9) quantified the trade-off between angular coverage (4.0 % → 100 % detection rate on an angled panel) and lateral edge inflation (0.088 m → 0.562 m RMSE) while confirming stable range bias (−0.040 to −0.049 m)[15].

Limitations & scope

  • Hardware vs. simulation campaign scope: Statistical multi-maze reliability (10/10 benchmark mazes and 12/12 repeatability runs) was established in Gazebo simulation, whereas physical robot evaluation comprised a single full-stack autonomous maze traversal (42/43 goals reached) supplemented by benchtop sensor and PCB characterization[1][3]. All reported robot runs used the dual-Arduino Mega + RAMPS ring controller; the custom STM32H7 ultrasonic node was verified at the bench prototype level[6].
  • Azimuthal beam width and dead-reckoning drift: Wide acoustic cones smear wall thickness and corners, yielding modest occupied-cell IoU (0.151 on hardware; 0.067–0.151 in simulation) despite high free-space topology accuracy (0.902–0.921)[4][10]. Because pose estimation relies solely on wheel encoders and an IMU without scan-matching loop closure, terminal localization error reached 0.025–0.119 m across the simulated maze suite[10].
  • Static benchmark configuration: An optional temporal decay and dynamic-obstacle classification layer (enable_dynamic_layer) is implemented in the mapping node but remained disabled (false) during the reported static maze benchmarks[5].
